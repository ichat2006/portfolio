GT Movies Store

A Django movie-store project built for CS 2340 with movie browsing, accounts, cart and checkout, orders, reviews, and a deployed web version.

Live application Course repository

GT Movies Store description

The site lets users browse and search movies, open a movie page for details, create an account, add movies to a cart, place orders, view order history, and write reviews.

  • Movies: browse, search by title, and view movie details.
  • Accounts: register, log in, and log out.
  • Cart and orders: add quantities, review the cart, purchase movies, and view previous orders.
  • Reviews: create, edit, and delete your own reviews.
  • Reporting: users can report another user's review, and reported reviews are hidden from the public movie page.
  • Admin: the site administrator can manage application data through Django Admin.

Process description

I mostly followed the step-by-step process in Django 5 for the Impatient. I built the project a section at a time, tested each feature locally, and fixed issues as they came up before moving on.

When I got stuck, I compared my code with the textbook, used Django's error messages to find the problem, and tested the page again. Most of the work was learning how the different parts of a Django project connect together and making sure each feature worked correctly.

I also added the review-reporting requirement and deployed the finished project to PythonAnywhere. Overall, the project helped me become more comfortable building, debugging, testing, and deploying a complete web application.
